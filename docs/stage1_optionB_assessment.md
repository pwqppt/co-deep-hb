# Option B (보정 후 검증) 평가 — 실행하지 않음, 교수님 결정 필요 (2026-10-09)

## 1. 보정할 lumped 파라미터 1개
- **선택: 산화막의 유효 수평 강성 E_ox,eff.** 구성은 R26(측벽 sliding, 캡 없음)이고, 부호가 맞는 유일한 구성군이다.
  - 수평 유연성의 81 %를 산화막이 차지한다(해석식, R26으로 보정).
  - 모든 패드에 같은 메커니즘으로 작용하는 스칼라 하나다.
- **필요한 값: 약 160 GPa** (R26 보정 해석식으로 구한 값).
  - FEM에서는 더 클 수 있다. 라이너의 경우 해석식이 FEM보다 증가분을 2.7배 과대평가했기 때문이다(R29·R30).
  - 확정하려면 FEM 2–3점으로 범위를 좁혀야 한다.
- **문헌 범위: 48–85 GPa.**
  - SiO2 박막 48–70, PECVD SiOx 74.8 ± 3.3, CVD-TEOS 85 ± 4, 열산화막 약 70
  - **필요값이 상한의 약 1.9배이므로 물리적으로 타당하지 않다.**
- 결국 보정값은 산화막 물성이 아니라 미지 요인들을 뭉뚱그린 **현상론적 유효 구속도**로 해석해야 한다. 미지 요인은 계면 조건, 캡, 라이너, 추출 방식 등이다.
- 대안 파라미터인 α_Cu,eff는 27.9 ppm/K가 필요하다(문헌 16.5–19.6). 더 비현실적이라 제외한다.

## 3. 권고 (순서대로)
1. **저자 질문 발송(즉시).** 측벽·캡 경계조건과 라이너를 묻는다. 비용은 가장 작고 결과는 가장 결정적이다.
2. **Fig 2a/2c 디지타이즈와 나머지 패드 hkl 입력.** 실행이 없는 준비 작업이라 어떤 결정이 나와도 필요하다.
3. 저자 답이 없거나 늦으면 **Option B를 현상론적 모델로 명시해서** 진행한다.
   - pad 10 가열 곡선에 E_ox,eff 하나만 맞춘다.
   - Fig 2c 탄성 패드와 pad 3(소성 변형별)로 검증한다.
   - 사전 판정 기준을 미리 고정한다.
4. 연구 질문(방위·recess 대비 접합 여유)에 실제로 중요한 것은 u의 **E_z 민감도**다(Fig 5 기울기 −0.0132 nm/GPa). 보정 모델이 이 기울기를 재현하는지도 검증 항목에 넣을 것을 권한다. 단, Fig 5는 측정이 아니라 Ayoub의 FEM 출력이다.
